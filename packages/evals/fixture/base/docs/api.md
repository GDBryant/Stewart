# API

- `capitalize(s)`: upper-cases the first character.
- `words(s)`: splits on whitespace.
- `parseDuration(text)`: parses `1h30m`-style durations.
- `range(start, end)`: integers from `start` up to, not including, `end`.
- `cartTotal(items, rate)`: sum of `price * qty`, minus the discount `rate`.
- `loadConfig()`: the parsed `config.json`.
