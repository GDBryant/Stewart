# @stewart/setup

- Purpose: Setup assistance: rules scorer, AI-refined assignment, model benchmark, setup quick-probe queue, workspace/hardware scan
- Surface: `src/api.ts`
- Owns: `assign.ts` (`ROLE_PROFILES`, `scoreAssignments`, `meetsHardRequirements`), `recommend.ts` (`recommendAssignments`), `bench.ts` (`benchModel`, `BENCH_VERSION`), `probe.ts` + `probeDrain.ts` (per-channel drain/in-flight tracking) (`SetupProbeRunner`, `smokeModel`, `normalizeReason`, `orderSmokeCandidates`, `rankCandidates`), `smoke.ts` (generic `runBounded` + `smokeModel`), `smokeClaude.ts` (`smokeClaude`: claude-code engine-turn smoke for `claude-cli` candidates, wired via `ProbeRunnerDeps.smoke`, which receives `onSettle`), `usesEngineTransport` (conformance.ts), `setupContext.ts` (`scanWorkspace`, `gatherHardware`), `session.ts` + `sessionTypes.ts` + `sessionFiles.ts` (`SetupSession` state machine, draft/deps types, backup/write/restore helpers), `draftChannels.ts` (`addDraftChannel`/`removeDraftChannel`/`rollbackDraftChannels`: channels the wizard adds are written ahead of approval and rolled back on cancel)
- Depends on: `@stewart/catalog`, `@stewart/channels`, `@stewart/config`, `@stewart/kernel`, `@stewart/models`, `@stewart/roles-skills` (lower layers only; `scripts/layers.json`)
- Fake it: Scorer is pure; `recommendAssignments` takes a `Map<string, ManagedChannel>` of scripted channels; scan runs over `fakeHost()`
