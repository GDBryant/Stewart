# Security analysis — 2026-11-24 (v3.0.13, 250a4e5)

Scope: dependency audit, shell/permission guards, path confinement, local MCP server, webview CSP. Not covered: JetBrains Kotlin host (SecretStore only skimmed), sidecar RPC, provider code, evals/docker.

## Verified findings

| # | Sev | Finding | Evidence |
|---|-----|---------|----------|
| 1 | High | **Shell splitter misses substitution inside double quotes.** `ShellScanner.inDouble` (`modules/permissions/src/shell.ts:~52`) only handles `\` and the closing quote; `isSubshell` is checked only in plain state. `echo "$(id)"` and ``echo "`id`"`` return `["echo"]` (run against the code). Any allowlist/auto-approve or read-only-role decision based on `splitShellPrograms` can be bypassed with arbitrary command execution. | executed via temp vitest |
| 2 | High | **Process substitution not flagged.** `cat <(id)` returns `["cat"]`. `checkReadOnlyCommand` rejects `<`/`>` earlier, but other `splitShellPrograms` callers do not. | executed |
| 3 | Medium | **No symlink resolution for in-workspace paths.** `ProjectPaths.resolve` (`modules/tools/src/projectPaths.ts:46-59`) is purely lexical; `realpath` is used only for external read roots (`:74`). A symlink in the workspace pointing outside lets Read/Write/Edit tools escape confinement; `denyWrite` (`modules/tools/src/policy.ts:121`) is also lexical. | code read + grep: no `realpath`/`lstat` elsewhere in tools |
| 4 | Medium | **Dependency advisories** (`pnpm audit`, 11): vitest <3.2.6 critical (UI server file read/exec, dev-only), tinypool critical x2 (dev-only), preact 10.27.0–10.27.2 high (webview runtime — likely shipped), zod <4.6.6 high (runtime), yaml <2.8.3, glob, minimatch, @vitest/mocker moderate. `pnpm audit --prod` reports 3 (2 high, 1 moderate): preact, zod, yaml. | `pnpm audit` |

## Reviewed, no issue found
- Local MCP server (`modules/engines/src/mcp.ts:93-124`): binds 127.0.0.1 on an ephemeral port, 24-byte random bearer token, exact-path and method check, closed on abort. Minor: no request body size limit and no constant-time compare (low).
- Webview CSP (VS Code `extension.ts:78`, JetBrains `WebviewResources.kt:35`): `default-src 'none'`, nonce scripts. `localResourceRoots` restricted to `webview/`. No `innerHTML` in webview sources.
- No `shell: true`, `eval` or `new Function` in source (grep hits were `RegExp.exec`).
- Launcher/interpreter/dangerous-env deny sets in `shell.ts` are broad (sh, env, xargs, node, python*, LD_PRELOAD, NODE_OPTIONS...).
- `.stewart/` is denied for writes except `scratch/` (`projectPaths.ts:116`).

## Unverified hypotheses
- Read-only allowlist may include programs with write/exec flags beyond `WRITE_FLAGS` (e.g. `find -exec/-delete`, `sort -o`); not checked.
- JetBrains `SecretStore` storage and sidecar RPC authentication not reviewed.

## Recommended fixes
1. In `inDouble`, return fatal on `` ` `` and `$(` (and `${` if desired); in `inPlain`, flag `<(` and `>(`. Add tests for all five cases above.
2. Resolve `realpath` of the nearest existing ancestor in `resolve()` and re-check confinement; add a symlink-escape test.
3. Bump preact >=10.27.3, zod >=4.6.6, yaml >=2.8.3 (use pnpm overrides if transitive); bump vitest to a patched version.
